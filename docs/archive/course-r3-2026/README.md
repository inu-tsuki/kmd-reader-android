# 2026 Android 课程至 R3 阶段归档

> 归档日期：2026-07-14
> 最终范围：课程 R0–R2 成果与 R3-A–I + R3-K1

本目录是 Android Reader 本轮连续开发的历史快照，不再指导当前实施。

## 内容

- `product/`：课程 PRD、阅读体验与社区交互草案。
- `runtime/`：ViewModel、bridge、WebView runtime 与 UI 抽取的实施计划。
- `stages/`：课程第二、第三和第五阶段方案与测试记录。
- `r3/`：本地阅读器总计划、调研、H/I/K 实施计划、提示词和 K1 视觉证据。
- `future-drafts/`：在社区契约形成前写下的 R4 reader 设想。

## 阅读边界

- 这里的 R3-J/K2 是 deferred 来源，不是仍开放的 R3 工作包。
- R3 实际只持久化 issue draft；close/reopen 和正式提交没有获得本地或云端持久化语义。
- `future-drafts/r4-community-review-plan.md` 包含已失效的 `local_issue_overrides` 等假设，
  只能帮助理解早期问题，不能作为未来 API、schema 或同步实现依据。
- 当前完成边界、长期不变量和恢复方式以
  [`../../planning/roadmap.md`](../../planning/roadmap.md) 与
  [`../../planning/post-r3-reentry-backlog.md`](../../planning/post-r3-reentry-backlog.md) 为准。
